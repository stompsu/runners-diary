# 0029 – Web tier: nginx container on Container Apps (supersedes 0004)

**Status:** Accepted (M7 plan approved 2026-11-04; amended 2026-11-04 after Part A implementation, see the end)
**Date:** 2026-11-04
**Supersedes:** [0004](0004-web-hosting.md) (proposed; its option B is dropped, option A is chosen)

## Context

ADR 0004 preferred Aspire `PublishAsStaticWebsite` (a YARP container) and fell back to nginx if M7 found that the YARP site could not do SPA fallback or set security headers. Fixed requirements from earlier ADRs:
- The browser talks only to the web origin. `/api/*` is reverse-proxied to an API that has **internal ingress only** (0004 consequences).
- `redirect.html` must be served **without COOP** and with `Cache-Control: no-store` (0014 §3).
- Strict CSP (`script-src 'self'`, no `unsafe-eval`), with `worker-src 'self'` and the map hosts (0022 amendment), plus `ciamlogin.com` for MSAL (0014).
- GPX uploads up to 20 MB (0020). AI summary requests take up to about 65 s (M6 plan §5).
- Per-IP guest limits need the real client IP at the API (0011 §7).

Verified on 2026-11-04:
- `PublishAsStaticWebsite` is **experimental** (`ASPIREJAVASCRIPT001`, Aspire 13.6). Its documentation names no SPA-fallback option and no custom response headers or timeouts ([aspire.dev JavaScript deployment](https://aspire.dev/deployment/javascript-apps/)).
- Container Apps HTTP ingress has a **240 s request timeout**. It **appends** to `X-Forwarded-For`, and "only the rightmost IP is provided by Azure Container Apps". Apps in the same environment reach each other by app name ([ingress overview](https://learn.microsoft.com/azure/container-apps/ingress-overview), updated 2026-10-22).
- M7 deploys with hand-written Bicep, not Aspire publish ([ADR 0030](0030-azure-topology-iac-and-deployment.md)), so option B loses its main advantage: it was generated by Aspire.

## Decision

**Option A: an unprivileged nginx container (`web`) on Container Apps, external ingress, scale 0–2.** Files: `web/Dockerfile` (multi-stage: Node 26 `npm ci && npm run build` → `nginxinc/nginx-unprivileged:<pinned>-alpine`, port 8080) and `web/nginx/default.conf.template` (rendered by the image's envsubst entrypoint).

1. **Routing**
   - `/assets/*`: files only, a missing file returns 404 (no fallback).
   - `/api/*`: proxied to `${API_UPSTREAM}` (`http://api`, the internal app). The API path is not stripped.
   - Everything else: `try_files $uri /index.html` (SPA fallback for `/diary/2026/11`).
   - `robots.txt`: `Disallow: /`. This is a private app, and crawlers should not wake the API.
2. **Proxy settings**
   - `proxy_read_timeout` / `proxy_send_timeout` 120 s (nginx defaults to 60 s, below the ~65 s summary call).
   - `client_max_body_size 21m` (nginx defaults to 1 MB; the API enforces the real per-route limits).
   - `proxy_request_buffering off` for `/api/tracks` uploads.
   - The `Host` header is left as the upstream name, because the environment's internal ingress routes by host.
   - DNS is resolved at runtime (`resolver` from `/etc/resolv.conf`, upstream held in a variable), so nginx starts even while `api` has no replicas.
3. **Client IP normalisation**
   - `real_ip_header X-Forwarded-For`, `set_real_ip_from 0.0.0.0/0`, `real_ip_recursive off` take the **rightmost** address, which is the one ACA's edge appended.
   - nginx then **overwrites** `X-Forwarded-For` with that single address towards the API. Client-supplied chains never reach the API.
   - The API trusts any proxy (`KnownIPNetworks` `0.0.0.0/0`, `::/0`) with `ForwardLimit` 2. This is safe because only apps inside the environment can reach its internal ingress.
   - The rule is verified live before go-live (plan AC7).
4. **Response headers** (all responses unless stated):

   | Header | Value |
   |---|---|
   | `Content-Security-Policy` | `default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data: blob: <map hosts>; font-src 'self'; connect-src 'self' https://<subdomain>.ciamlogin.com <map hosts>; frame-src https://<subdomain>.ciamlogin.com; worker-src 'self'; frame-ancestors 'none'; base-uri 'none'; form-action 'self'; object-src 'none'` (map hosts per [ADR 0033](0033-production-maps-and-azure-maps.md); the tenant host comes from an env var) |
   | `Strict-Transport-Security` | `max-age=31536000` (no `preload`) |
   | `X-Content-Type-Options` | `nosniff` |
   | `Referrer-Policy` | `strict-origin-when-cross-origin` |
   | `Permissions-Policy` | `camera=(), microphone=(), geolocation=(), payment=()` |
   | `Cross-Origin-Opener-Policy` | `same-origin`, **except `/redirect.html`, which gets none** |
   | `Cache-Control` | `/index.html`, `/redirect.html`, SPA fallback: `no-store`; `/assets/*`: `public, max-age=31536000, immutable` |

   - `/api/*` responses pass through unchanged, so the API's `private, no-store` etc. still apply.
   - gzip for text types. `server_tokens off`.
   - If a CSP violation shows up in CI (inline style attributes, ADR 0022 amendment), the fix is the narrowest directive (`style-src-attr 'unsafe-inline'`), never `unsafe-inline` on `script-src`.
5. **No runtime config files.** The SPA keeps reading `/api/client-config` (0015). The only templated values are `API_UPSTREAM` and the CSP host list.

## Consequences

- One small image with full control and well-known semantics. Its config is covered by CI: the Playwright suite (fake API via `page.route`) runs against the built image and fails on any CSP violation, and `curl` assertions check the headers and the proxy limits (plan §6).
- The CSP must name the Entra tenant host, so it is environment-specific (env var), not baked into the image.
- nginx is one more hop in front of the API (ACA edge → nginx → ACA internal ingress → API); the `ForwardLimit` above accounts for it.
- The AppHost keeps using the Vite dev server locally. nginx exists only in the image (and in CI).

## Alternatives considered

- **Aspire `PublishAsStaticWebsite` (YARP), ADR 0004 option B:** experimental, with SPA fallback, headers and timeouts undocumented. It would also tie the deployment to Aspire publish. Rejected.
- **Static Web Apps:** needs a public API or the Standard plan's linked backends. Excluded by 0004.
- **ASP.NET Core serving the SPA from the API image:** one container fewer, but the API would get public ingress, which contradicts 0004. Rejected.
- **Caddy:** comparable and simpler TLS, but TLS is terminated by ACA anyway, and nginx's `realip` and header handling are better known. Rejected.

## Amendment (2026-11-04, M7 Part A implemented)

What was built (`web/Dockerfile`, `web/nginx/{default.conf.template,security-headers.conf.template,15-resolver.envsh}`). Normative where it differs from §1–§5 above.

1. **Image.** `nginxinc/nginx-unprivileged` alpine, non-root, digest-pinned, ≈ 27 MB compressed. Port 8080. Platform probes use a new `GET /nginx-alive` (200 `ok`, served by nginx, never proxied), so a web probe never wakes the API or SQL.
2. **Upstream (changes §1 and §2).** `API_UPSTREAM` is **`https://<api internal FQDN>`** (Bicep output of the `api` app), not `http://api`. nginx sets `proxy_ssl_server_name on`, `proxy_ssl_verify on` (depth 3) against the image's CA bundle, so the hop to the internal ingress is TLS with a verified certificate and the API needs no `allowInsecure`. The `Host` header is nginx's default (the upstream host), which the internal ingress routes by. The resolver still comes from `/etc/resolv.conf` (`15-resolver.envsh`) with the upstream in a variable, so nginx starts while `api` has zero replicas. The image default stays `http://api` (used with a plain-`http` stub in CI and locally, where `proxy_ssl_*` is ignored); Bicep always sets the `https` FQDN.
3. **Proxy (confirms §2).** `client_max_body_size 21m`, `proxy_read_timeout`/`proxy_send_timeout` 120 s, `proxy_connect_timeout` 10 s, `proxy_request_buffering off` for `POST /api/runs/{id}/tracks`. `X-Forwarded-For` is the **rightmost** address (`real_ip_recursive off`, `set_real_ip_from 0.0.0.0/0, ::/0`) and is **overwritten** with that single value; `X-Real-IP` is cleared; `X-Forwarded-Proto` passes only `http`/`https`. Security headers the API might send are hidden and replaced with the web tier's own; all other API headers (`Cache-Control` etc.) pass through.
4. **Routing (confirms §1).** `/assets/*` uses `try_files $uri =404` (a missing asset is a 404, never the SPA). `immutable` is added without `always`, so a 404 is not cached for a year. `/index.html`, `/redirect.html` and the SPA fallback are `no-store`. `robots.txt` is cached for 1 h.
5. **MIME fix.** The base image's `mime.types` has no `.mjs`. MapLibre's module worker is `.mjs`; under `nosniff` with `application/octet-stream` the worker failed to load. The config adds `types { text/javascript mjs; }`.
6. **CSP as implemented (replaces the §4 row).** Templated by envsubst with an `NGINX_ENVSUBST_FILTER` so only `${API_UPSTREAM}`, `${NGINX_RESOLVER}` and `${CSP_*}` are substituted:

   ```
   default-src 'self'; script-src 'self'; style-src 'self' ${CSP_STYLE_HASHES};
   img-src 'self' data: blob: ${CSP_MAP_HOSTS}; font-src 'self' ${CSP_MAP_HOSTS};
   connect-src 'self' ${CSP_ENTRA_HOST} ${CSP_MAP_HOSTS}; ${CSP_FRAME_SRC};
   worker-src 'self' blob:; frame-ancestors $rd_frame_ancestors;
   base-uri 'none'; form-action 'self'; object-src 'none'
   ```

   - **`style-src`:** no `'unsafe-inline'` and no `style-src-attr` exception. `CSP_STYLE_HASHES` (baked into the image) lists the `sha256` hashes of the `<style>` elements that Sonner and react-remove-scroll inject at runtime. A library upgrade that changes that CSS fails the CI CSP fixture, and the hash is updated in `web/Dockerfile`.
   - **No `unsafe-eval`:** zod 4 probes `new Function` for its JIT; `web/src/features/runs/runFormSchema.ts` sets `z.config({ jitless: true })` so no violation is reported.
   - **`worker-src 'self' blob:`** (was `'self'`): MapLibre and the Azure Maps SDK create blob workers.
   - **`font-src`** includes the map hosts (glyphs; Azure Maps fonts when G9 is on).
   - **`frame-src`:** `'self' <entra host>` when `CSP_ENTRA_HOST` is set (MSAL's silent-renewal iframe starts at the tenant and ends on our `/redirect.html`), otherwise `frame-src 'none'`. Computed in `15-resolver.envsh`.
   - **`frame-ancestors`:** `'none'` everywhere **except `/redirect.html`, which gets `'self'`** so MSAL's same-origin hidden iframe can load it.
   - **COOP** `same-origin` everywhere except `/redirect.html` (unchanged).
   - The default `CSP_MAP_HOSTS` is `https://tiles.openfreemap.org`. The image deliberately ships **no Azure Maps hosts**; Bicep adds `https://eu.atlas.microsoft.com https://atlas.microsoft.com` only with G9.
7. **CI proof.** Playwright honours `PLAYWRIGHT_BASE_URL` (no `webServer`), and the shared fixture fails a test on any `securitypolicyviolation` event or CSP console error. `web/e2e/csp-guard.spec.ts` injects a violation on purpose and asserts the fixture catches it, so the guard cannot silently stop working. The `deploy-artifacts` job runs the whole suite against the built image plus a header-verify script (the curl assertions of plan §7.1). `e2e-fullstack` runs the built `api` and `web` images.

**Still unverified (⚠, closed at Part B):** MSAL silent renewal under this CSP against the real tenant (G8); the Azure Maps Web SDK under the CSP with real tiles (G9); the live XFF behaviour (AC9, G5).
